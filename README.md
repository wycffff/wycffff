## Public projects

### [Weld Map & Traceability Assistant](https://github.com/wycffff/Weld_map_understanding_and_weld_traceability_assistant)

Extracts weld information from engineering drawings using OCR, then stores it in SQLite. The Streamlit interface lets users review the results, update weld status, and export records. A vision-language model can assist with extraction when needed.

### [AIS Vessel Tracking](https://github.com/wycffff/ais_vessel_tracking_project)

Receives live vessel data through MQTT, stores it in PostgreSQL, and displays it on a map with WebSocket updates. A FastAPI backend serves the data, and an LLM agent answers vessel queries using database tools. Short-term position estimates use speed and direction.

### [Nordic Travel AI](https://github.com/wycffff/nordic-travel-ai)

A travel planner for Finland and the Nordic countries, built with Flask and a local model running through Ollama. It generates itineraries and streams the response to the browser.

### [TPS Playoff Probability](https://github.com/wycffff/TPS24-25_playoff_probability)

Uses Monte Carlo simulation to estimate TPS's chances of reaching the 2024–25 playoffs. The calculation reflects the situation on February 23, 2025.
